## CÓMO USAR ESTE MANUAL

Este documento es el sistema operativo completo de VESTRA como firma de consultoría. No es un ebook ni material de marketing: es el manual interno que gobierna cómo vendemos, cómo diagnosticamos, cómo intervenimos, cómo entregamos, cómo medimos y cómo escalamos. Cada consultor, director de proyecto y analista que se incorpore a VESTRA debe operar bajo estos estándares sin excepción. Cada capítulo vive en su propio archivo dentro de esta carpeta para poder editarse, versionarse y distribuirse de forma independiente.

Estructura de carpetas:

```
VESTRA-OS/
├── 00-INDICE-MAESTRO.md          ← este archivo
├── TOMO-I-VISION/                ← capítulos 1-8
├── TOMO-II-VESTRA-OS/            ← capítulos 9-16
├── TOMO-III-PLAYBOOK-COMERCIAL/
├── TOMO-IV-IMPLEMENTACION/
├── TOMO-V-MARKETING/
├── TOMO-VI-OPERACION/
├── TOMO-VII-ESCALAMIENTO/
└── ANEXOS/                       ← formatos, contratos, dashboards, scripts
```

# TOMO VIII — CAJA DE HERRAMIENTAS COMPLEMENTARIA
## Tabla de Selección, Plan de Implementación y Checklist

---

## 1. Regla de selección

Nunca se aplican las 35 herramientas a un mismo caso. Se cruza el problema del cliente contra esta tabla y se eligen 4-6 herramientas como máximo — el resto de este Tomo queda como referencia, no como lista de tareas.

## 2. Tabla de Selección — qué herramienta usar y cuándo

| Escenario / Desafío | Herramientas Clave | Duración típica | Output esperado |
|---|---|---|---|
| Diagnóstico rápido | FODA + Modelo Iceberg | 2-3 días | 3-5 problemas clave identificados |
| Alto impacto estratégico | 7S McKinsey + Balanced Scorecard | 4-6 semanas | Estructura alineada con estrategia |
| Problemas operativos | AS IS → TO BE + Gantt | 6-8 semanas | Flujos de trabajo estandarizados |
| Innovación / creatividad | Design Thinking + Now-How-Wow | 3-5 semanas | Propuesta de valor validada |
| Resistencia al cambio | ADKAR + Matriz de Stakeholders | 8-12 semanas | Plan de adopción con apoyo crítico |
| Lanzamiento de producto | Design Thinking + BMC | 3-5 semanas | Modelo de negocio validado |
| Competitividad de mercado | 5 Fuerzas de Porter + Benchmarking | 2-4 semanas | Estrategia competitiva clara |

**Nota de uso VESTRA:** cuando el escenario corresponde a un cliente dentro de la Instalación estándar de 90 días (no un proyecto de escalamiento aparte), estas duraciones no reemplazan el roadmap del Tomo IV — la herramienta se aplica como insumo interno del consultor dentro de la semana que corresponda, sin extender el plazo del proyecto.

## 3. Plan de Implementación — 5 Fases (para proyectos de escalamiento, Cap. 16 Tomo II)

Este plan de 5 fases se usa **únicamente** en proyectos de escalamiento del cliente (Cap. 16, Tomo II) que ya salieron del roadmap fijo de 90 días — nunca en la Instalación VESTRA OS™ estándar, que sigue su propio roadmap (Tomo IV).

```
FASE 1 · Preparación (10-20% del tiempo del proyecto)
   Matriz de Stakeholders + Roadmap. Taller inicial con VAMO (ya cubierto
   por el DAE existente del cliente, Cap. 10.2 Tomo II — se revisa y
   extiende, no se repite desde cero).

FASE 2 · Profundización Analítica (20-30%)
   Cadena de Valor + 5 Fuerzas + Benchmarking en los eslabones críticos
   del nuevo vector de escalamiento (Cap. 16.3, Tomo II).

FASE 3 · Diseño de Soluciones (30-40%)
   Sesiones +1-2-4 + Design Thinking. Prototipo/MVP rápido.

FASE 4 · Ejecución Controlada (15-25%)
   Modelo de Kotter, enfoque en Quick Wins. Storytelling para comunicar
   avances al equipo. Monitoreo con BSC y Gantt.

FASE 5 · Institucionalización (5-10%)
   Niveles Neurológicos de Dilts para anclar en cultura. Curva de
   Greiner para anticipar la siguiente crisis de crecimiento. Cierre:
   el resultado se traduce a una nueva Roca trimestral o a un ajuste
   del DAE (Cap. 10.2, Tomo II), nunca queda como documento aislado.
```

## 4. Checklist de Implementación

```
ANTES DE COMENZAR
☐ Definir objetivo SMART con los líderes del cliente
☐ Asignar "campeones" por área
☐ Confirmar que el proyecto es de escalamiento (Cap. 16, Tomo II),
  no parte de la Instalación estándar — si es lo segundo, usar el
  roadmap del Tomo IV, no este plan de 5 fases

DURANTE
☐ Check-ins semanales con Balanced Scorecard o el Dashboard VESTRA
  ya instalado del cliente (Cap. 12, Tomo II) — no crear un tablero
  paralelo si el cliente ya tiene uno funcionando
☐ Documentar lecciones aprendidas

AL FINALIZAR
☐ Evaluar resultados vs. KPIs iniciales
☐ Crear manual de buenas prácticas del proyecto específico
☐ Traducir el resultado a lenguaje VESTRA (nueva Roca, ajuste de DAE,
  o nuevo indicador en el Dashboard) antes de cerrar con el cliente

RIESGOS COMUNES
☐ Falta de adopción → aplicar Modelo de Lewin para descongelar
☐ Datos insuficientes → Voz del Cliente (VOC) con encuestas rápidas
☐ El proyecto se empieza a sentir "genérico" para el cliente → volver
  a leer la regla de uso del archivo `00-cuando-usar-este-tomo.md`:
  estas herramientas son para pensar, nunca para presentar
```

## 5. Registro de origen

Este Tomo se incorporó al manual a partir de una base de conocimiento previa de VESTRA ("Manual de 35 Herramientas de Consultoría — Vestra Consultoría en Negocios · Estructura Empresarial™"), adaptada y cruzada explícitamente contra la metodología VESTRA OS™ de los Tomos I-VII para eliminar redundancia y fijar reglas claras de cuándo sí y cuándo no se usa cada herramienta frente al cliente.
